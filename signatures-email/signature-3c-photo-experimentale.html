Installation
  1. Ouvrir ce fichier dans Chrome, Edge ou Firefox.
  2. Sélectionner la signature dans le cadre « ordinateur » (de « Abdoulhakim » jusqu'à la dernière ligne), puis Ctrl + C.
  3. Outlook : Fichier › Options › Courrier › Signatures › Nouvelle › coller (Ctrl + V).
    Outlook Web : Paramètres › Courrier › Composer et répondre › coller.
    Gmail : Paramètres › Voir tous les paramètres › Signature › coller.
  4. Avant de coller, vérifier que le logo et la photo s'affiche bien dans le cadre ci-dessus.

Logo : en attente du logo officiel ; tant qu'il n'est pas fourni, seul le texte alternatif « DIR Est » s'affiche. Déposer le logo officiel sous le nom logo-dir-est.png à côté de ce fichier (PNG, environ 180 px de large pour un affichage net à 90 px). Pour que le logo s'affiche chez vos destinataires, il doit être hébergé à une adresse https publique (intranet exposé, site de la DIR Est…) et l'attribut src doit pointer vers cette URL ; à défaut, insérez l'image directement via le bouton « Image » de l'éditeur de signature d'Outlook. Gmail n'accepte pas les images en pièce jointe locale ni en base64 dans les signatures.

Photo (version expérimentale) : en attente de la photo ; tant qu'elle n'est pas fournie, seul le texte alternatif s'affiche. Elle sera recadrée sur le visage, au format carré puis en rond, et enregistrée sous photo-abdoulhakim.png (152 x 152 px pour un affichage net à 76 px, sans déformation). Le rond est intégré à l'image elle-même, car Outlook pour Windows ignore les coins arrondis en CSS. Comme le logo, la photo doit être hébergée à une adresse https publique pour s'afficher chez les destinataires.
