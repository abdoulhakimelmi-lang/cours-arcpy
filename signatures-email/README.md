Ouvrir un fichier dans le navigateur : l'aperçu montre le rendu ordinateur et mobile,
ainsi que la procédure d'installation dans Outlook / Outlook Web / Gmail.

Technique : tableaux HTML + styles inline uniquement, police Arial, aucune image
obligatoire (hors version logo), aucun JavaScript, aucune ressource externe.
Les lignes facultatives (téléphone, LinkedIn) sont repérées par des commentaires HTML.
